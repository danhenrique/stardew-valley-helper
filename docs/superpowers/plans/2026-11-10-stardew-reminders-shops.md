# Weekly Reminders and Shop Hours Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show today's recurring reminders and closed shops in the "Hoje" card, add a `/lojas` page with each shop's status and hours, and store the player's progress flags that change shop hours.

**Architecture:** Reminders flow through the existing pipeline (`game-data` JSON → DynamoDB `Reminder` entity → generic `/game/lembretes` → website). Shop schedules already flow the same way (`/game/lojas`). The website computes "today" in pure `lib/` functions from the profile date and the new profile flags.

**Tech Stack:** Python 3 (`build-data.py`, PynamoDB, FastAPI/Powertools, pytest + moto), React + TanStack Router/Query, Tailwind, Heroicons, Vitest + Testing Library, Nx + pnpm.

**Spec:** `docs/superpowers/specs/2026-11-10-stardew-reminders-shops-design.md`
