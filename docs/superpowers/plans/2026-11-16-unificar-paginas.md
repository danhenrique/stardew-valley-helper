# Merge Events into Calendar and Plantings + Machines into Production Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `/calendario` into a two-tab page (Calendário, Eventos), add `/producao` with tabs (Plantios, Máquinas), redirect `/eventos`, `/plantios`, `/maquinas`, and cut the menu to 6 items.

**Architecture:** TanStack Router file routes in `packages/website/src/routes`; the tab lives in the search param `aba`, parsed with `validateSearch`. Each current page body moves to a tab component in `components/`; route files only compose `UnderlineTabs` + the active tab. Old routes use `beforeLoad` + `redirect`.

**Tech Stack:** React, TanStack Router (file-based, `routeTree.gen.ts` generated by the Vite plugin), Tailwind, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-16-unificar-paginas-design.md`

## Global Constraints

- Branch `feature/unificar-paginas` from `main`; at the end commit, push and open a PR to `main`.
- UI labels in pt-BR; code in English; Tailwind only; light and dark theme.
- Search param name `aba`; values `calendario` | `eventos` on `/calendario`, `plantios` | `maquinas` on `/producao`; missing or invalid → first tab.
- Tab switches use `navigate({ search: { aba }, replace: true })`.
- Menu order: Hoje, Produção, Sementes, Peixes, Calendário, Lojas.
- Run through Nx: `pnpm nx test website`, `pnpm nx run-many -t lint test build`.

## Review Focus

- Deep link `/producao?aba=maquinas` on first load (not only via tab click) renders Máquinas and highlights "Produção" in the menu.
- Old bookmark `/eventos` lands on `/calendario?aba=eventos` (and `/eventos/$id` still shows the event, not a redirect).
- Opening a drawer in one tab then switching tabs does not leave a drawer open over the other tab.
- Browser back after switching tabs leaves the page instead of cycling through tabs (`replace: true`).
- `?aba=` with an unknown value (e.g. `?aba=xyz`) falls back without a crash or a blank page.
